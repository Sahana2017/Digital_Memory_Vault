# Digital Memory Vault

A secure personal digital life organizer developed using the MERN Stack.

## Project Overview

Digital Memory Vault allows users to securely store, organize, search, and manage their personal digital memories such as photos, videos, documents, and notes.

## Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- HTML
- CSS
- JavaScript

## Main Features

- User Registration and Login
- Secure Authentication
- Add and Manage Memories
- Upload Photos, Videos, and Documents
- Search and Categorize Memories
- Edit and Delete Memories
- User Profile
- Dashboard
- Change Password

## Project Structure

```text
Digital_Memory_Vault
├── Frontend
└── Backend
```

## How to Run

### Frontend

```bash
cd Frontend
npm install
npm start
```

### Backend

```bash
cd Backend
npm install
npm start
```

## Project Purpose

The project provides a secure and organized platform for users to preserve and manage their important digital memories in one place.
